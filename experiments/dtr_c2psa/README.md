# b19 + DTR-C2PSA（双代表区域交互模块）

独立实验分支 `exp/dtr-c2psa-b19`，唯一源码基线为
`4a1b167dee2b0c7353d9d7ead2911383d1ebf1d6`。正式服务器训练：**NOT_STARTED**；本次没有完整数据集 val/test，也没有精度或速度优越性结论。

## 结构与状态边界

`yolo26n-dtr.yaml` 只替换第 10 层。外层 `cv1/cv2` 保持原名和语义，原 `model.10.m.*` 整体移除，新状态全部在
`model.10.dtr_blocks.*`。640 输入时第 10 层为 `B×256×20×20`，两条分支各 128 通道，处理分支串行执行两个独立块。
每块包含 32/32/64 通道的 DW3/DW5/DW7、通道 LayerNorm、5×5 非重叠区域的 mean/detail 双代表、两头区域注意力、
门控回写、隐藏宽度 256 的 CGLU。每头 Q/K/V 为 64 维，注意力矩阵为 `400×50`。Detect 输入保持 `[16,19,22]`。

这是完整替换，有新增随机参数及删除的原生参数，**不保证初始整网函数等于 b19**。没有移植形状相似但语义不同的 QKV/FFN 参数，
没有新增辅助损失、监督分支或检测尺度。复用原生 Conv、DetectionTrainer、损失、MuSGD、EMA、融合和检查点加载。
LayerNorm 使用内含 `nn.LayerNorm` 的 NCHW 包装，使原生优化器正确识别归一化参数。

`DTRTrainer.get_model` 按原生加载顺序创建 nc=1 参考模型，保留分类头适配的原生初始化，再在 RNG 隔离范围内创建新模型并逐键复制。
复制核对键集、形状、模块类型、其他层配置、逐张量一致性和独立存储。参考模型不留作子模块。
显式训练检查点由 `DTRTrainer.setup_model` 直接加载，已保存的原始 `pretrained` 路径不会覆盖已学习状态；EMA、预测和融合不重走新训练初始化。

所有机制字段与存档 `baseline_args.yaml` 逐项对照，只允许运行路径和明确设备表示改变。该存档来自用户已有的 b19 导出结果，
不是从当前默认值拼装的配方。报告保留原配置、解析配置及逐字段差异。

原始权重必须匹配 SHA256 `9b09cc8bf347f0fc8a5f7657480587f25db09b34bf33b0652110fb03a8ad4fef`。
数据检查包括 YAML 语义/哈希、8414/2404/1202 张 train/val/test 图像和 2985/1477 个 val/test 框；未计算整份数据内容哈希。
本地权重可直接指向母仓库的文件；本地验证不会下载或改写该文件。

`--dry-run` 在临时目录实际调用 Trainer 构造和 setup_model/get_model，不训练、不建立正式输出目录。
审计报告必须置于正式输出目录之外。正式入口 `resume=False`，已存在的输出目录报错，并原子创建唯一输出目录以防并发覆盖。
正式运行前核对服务器 Python/Torch/TorchVision/CUDA/GPU/Albumentations 环境，差异时报错，不安装或调整环境。
`YOLO_AUTOINSTALL=false`；正式训练的原生 AMP 检查复用 worktree 内核验过的同名原始权重。
有限验证把核验过的副本放入临时目录供 AMP 检查读取；检查点重载及子进程也从该目录读取，退出后恢复调用目录。

原生训练循环的 OOM 重试上限改为由 Trainer 类持有：其他实验默认仍为 3，本实验为 0，在降低 batch 之前直接抛出 OOM。
训练开始前再次核对实际 batch=32、imgsz=640、AMP 和 MuSGD。没有 GPU 排队或停止其他进程的逻辑。

独立评价入口固定 FP32、640、batch32、conf0.001、iou0.7、max_det300、rect=True、augment=False、quantize=None、
end2end=True 和原生 fuse。记录实际输入/模型 dtype、源码和权重身份、P/R/F1/AP50/AP75/mAP50–95。
AP75 从实际 IoU 阈值数组查找 0.75；conf0.25/0.50 的 P/R/F1 明确为 PR 曲线插值估计，不提供伪造的精确 TP/FP/FN。
原生 P/R 是各模型自身最佳平滑 F1 工作点，不能当作共同置信度结果。阈值选择应仅在 val 完成，再固定用于 test。

## 诊断与研究边界

每个块默认 `diagnostics_enabled=False`；需要时单独设为 True，执行前向后读取该块 `diagnostics`，获取最近一次前向在 batch/空间上的聚合统计。
包括区域内容权重归一化熵、mean/detail 相对差异、门控均值/标准差/最小/最大值、每头两类代表的注意力质量及有限性。
单像素区域的归一化熵记为 0，并单独报告数量。

初始合成 640 输入的两个块熵均接近 1，代表相对差异约 4.45e-5/6.17e-5，两类注意力质量接近各 0.5，初始门控为 0.5。
这说明初始两种代表很接近，不能解释为已经识别裂缝；当前检查不能判断真实数据中的背景响应偏强问题。
该实现遵循用户指定的组合结构，没有直接复制用户模块包，也不将其表述为既有论文的完整复现、已证明的首创或已超过 b19。
