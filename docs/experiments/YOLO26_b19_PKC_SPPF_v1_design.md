# PKC-SPPF v1：池化—卷积互补金字塔

设计日期：2026-09-08。状态：候选结构设计，尚未实现或训练。PKC 为本项目工作名称（Pooling–Kernel Complementary），不表示已确认论文首创。

## 1. 本轮选择

暂缓 SD-P2，设计一个只替换 b19 第 9 层 SPPF 的独立模块：PKC-SPPF。

核心是保留原来的最大池化金字塔，同时增加低通道的可学习卷积金字塔。两路在相同的 5/9/13 特征网格范围内，用不同方式聚合信息：池化提供极值响应，卷积学习有空间权重的局部与上下文模式。

本方案不继续 SIR 的相邻池化差分路由，不添加 SE/CBAM 等乘法门控，不使用预设方向条形卷积，也不叠加 MSI、MPDF、RSC、DSD 等其他实验模块。

## 2. 为什么值得单独试一次

最大池化在一个窗口中输出最大值，其聚合不显式编码窗口内其他响应的排列；可学习卷积可以利用相对位置和多个邻域响应。对于裂缝，待验证的假设是：除了强响应本身，周围语义特征的连续组合也有助于区分目标与背景。

这里不能声称原 SPPF 丢失全部细节：其输入投影 Z 本身参与拼接，YOLO26 此处还有外层残差。新增分支的作用是增加一种可学习的空间聚合方式，而不是恢复已被输入缩放或骨干下采样彻底删除的图像信息。

SPPF 位于 P5/32，在 640 输入时只有约 20×20 的特征网格。因此，本方案主要针对深层特征表达和后续融合，不承诺直接恢复像素级细裂缝。预期方向是改善 AP50–95、AP75，并观察相近误检水平下的召回；没有依据承诺具体涨点幅度。

## 4. 原生 SPPF 核对

本次读取模块包的 `ultralytics/nn/modules/block.py`，并核对已上传 DSD 结果包 `source.tar` 中的原生 SPPF，两者相关实现一致。结果包中 block.py 的 SHA256 为 `20eda06be7ad7fea69db8161c91f6681371aa6aedb1dcae18db1a004783e1cbd`。真正实现时仍须对照 b19 固定提交。

原生接口为 `SPPF(c1,c2,k=5,n=3,shortcut=False)`。b19 第 9 层的 YAML 参数为 `[1024,5,3,True]`，nano 缩放后的输入与输出均为 256 通道，隐藏通道为 128。

```text
Z  = cv1(X)                         # 256→128，Conv+BN，act=False
M1 = MaxPool5(Z)                    # stride=1, padding=2
M2 = MaxPool5(M1)
M3 = MaxPool5(M2)
B  = cv2(concat(Z,M1,M2,M3))        # 512→256，保留原 Conv/BN/SiLU
Y0 = B + X                         # 本配置 add=True
```

三次池化保持空间尺寸不变，其对 Z 的理论空间范围依次为 5×5、9×9、13×13。这是特征网格上的范围，不是原图像素范围，也不是模型完整的有效感受野测量。

## 5. 固定首版结构与公式

保留上面全部原生路径，从 Z 分出新增卷积路径。首版内部宽度固定 r=32。

```text
U   = Conv1x1(128→32)+BN+SiLU (Z)
L5  = DWConv5x5(dilation=1,padding=2)+BN+SiLU (U)
L9  = DWConv3x3(dilation=2,padding=2)+BN+SiLU (L5)
L13 = DWConv3x3(dilation=2,padding=2)+BN+SiLU (L9)
Delta = Project1x1(96→256)(concat(L5,L9,L13))
Y = Y0 + Delta
```

全部卷积 stride=1、bias=False；三个空间卷积 groups=32。`Project1x1` 是普通卷积，不带 BN、不带激活，权重初始化为零。其余新增卷积采用正常初始化，BN 的 gamma=1、beta=0，不把整条分支清零。

L5/L9/L13 对 U 的卷积空间范围分别为 5/9/13，计算为 `5`、`5+(3-1)×2=9`、`9+(3-1)×2=13`。先用密集 5×5，再用 dilation=2 的 3×3，理论输入支持连续覆盖对应窗口；这不代表训练后各位置必定有同样贡献。

这个范围与原池化三级对应，但两个算子的输出不必相同。新分支不乘以 M1/M2/M3，也不使用 Mi−M(i−1)。拼接后的投影自由学习三个尺度及通道的组合，允许正负补充。

**融合点固定在原 SPPF 完整输出之后。** 不改原 cv2 的输入维度，不把新分支插入其 BN 之前，不额外给最终输出添加 BN 或激活。通用接口中应先按原 add 标志形成 Y0，再加 Delta，不能无条件执行 X 残差。

## 6. 与既往实验的机制区别

| 模块                | 聚合/修正对象             | 主要变化                                   |
| ------------------- | ------------------------- | ------------------------------------------ |
| SIR-SPPF 已核实首版 | 相邻池化输出的增量        | 路由权重调整并累积池化差分                 |
| PKC-SPPF            | 原投影特征 Z              | 新增可学习空间卷积金字塔，与完整原输出相加 |
| MSI-C2PSA           | 第 10 层 C2PSA 的内部特征 | 在不同模块位置构建特征变换                 |
| MPDF-P3             | neck 的 P3 融合           | 改变上采样和跨层融合                       |

PKC 与 SIR 都可使用“初始新增项为零”的兼容策略，但这不意味着它们具有相同的空间运算机制。零初始化仅是让新实验从 b19 既有输出开始学习的方法，不是模块的论文创新点。

## 7. 参数与计算预算

以下为上述固定结构在 nano、640 输入、20×20 特征图下的静态计算，不是实测报告。

| 新增部分              | 参数量（含 BN 可学习参数） |
| --------------------- | -------------------------: |
| 128→32 的 1×1 Conv+BN |                      4,160 |
| 32 通道 DW5+BN        |                        864 |
| 两层 32 通道 DW3+BN   |                        704 |
| 96→256 的输出投影     |                     24,576 |
| 合计                  |                     30,304 |

若原模型总参数为 2,504,190，则预计为 2,534,494，增加约 1.21%。按乘加=2 FLOPs 计算，新增卷积约 0.0240 GFLOPs，不计 BN、激活、拼接、加法、访存及框架调度。

分支算在 P5 上，静态成本较低；实际延迟不由 FLOPs 单独决定，仍需统一条件下实测。保留原最大池化，因此不能声称降低了原 SPPF 的池化成本或整体模型一定更快。

## 8. 初始化、预训练与实现约束

1. 只替换第 9 层，建议类名 `SPPF_PKC`，外部输入、输出、原始层索引不变。保留原 `cv1/cv2/m/n/add` 与对应 state_dict 路径。
2. 先核对真实 b19 初始化流程、原始预训练权重和全部共有张量。不能因为新增模块消耗随机数而悄悄改变其他未匹配层的初始化；可复制同一基准初始化状态来建立严格对照。
3. 输出投影为零时，在相同权重、BN 状态、输入和精度下验证全模型初始化等价。等价意味着起点一致，不保证训练后的优化轨迹或结果更好。
4. 零投影使第一步新分支上游卷积通常没有梯度，输出投影应有有限、有效梯度。投影更新后，再检查上游卷积梯度和权重变化，不能要求第一步所有新参数均非零梯度，也不能同时把投影和一个外部乘法系数设为零。
5. 保留 native Detect、one-to-many/one-to-one、detach、损失、分配策略和后处理。新分支位于 backbone，无需单独改检测头梯度边界。
6. 采用现有 Conv 类的 BN 约定以兼容 fuse；原 cv1 的 act=False 保持不变。三层卷积间有 SiLU，因此它们不能精确合成单个线性大卷积，不能宣称该分支推理时可整体重参数化为一层。
7. 验证方形和矩形输入、BN 更新、AMP/FP32 有限性、真实 MuSGD 更新、EMA、保存重载、fuse 和真实 Validator。评估/融合比较使用独立模型副本与原生同条件对照，不无依据放宽误差阈值。
8. 如为其他模型规模提供支持，应明确如何确定 r；本实验仅固定 nano 的 r=32，不在首版自动扫描通道数或核组合。

## 9. 训练与评价

使用独立实验分支与输出目录，从原生 b19 开始，只改变 SPPF 结构及实验输出路径。保留 MSI、MPDF 和其他实验的工作树与结果。

完整继承真实 b19 args.yaml、启动参数与数据划分：batch=32、imgsz=640、epochs=200、patience=60、MuSGD、seed=42、AMP=True；其余参数读取原始配置，不能手动重新猜填。预检和正式训练均为 batch32，资源不足就等资源或顺序运行。

统一独立 FP32 val/test：imgsz640、batch32、conf0.001、iou0.7、max_det300，其余参数与既有统一评估保持一致。记录 split、best.pt SHA256、源码提交、精度和完整评估参数。

主要看 mAP50–95 和 AP75，同时记录 AP50、P、R、PR 曲线及各类错误。继续关注召回，但不通过降低置信度或抬高 max_det 来制造涨点。对比验证集相同 Precision 或相同 FPPI 下的 R；若选择运行阈值，只在 val 确定，再冻结到 test。

建议固定 16 张验证图作特征诊断，记录 `||Delta||/(||Y0||+epsilon)`、三级特征统计和梯度，以及最终 TP/FP/FN 的变化。这个比值是分支贡献诊断，不是模块有效性的充分证据；训练后关闭分支只属于推理诊断。

先做一个固定首版，不同时堆叠其他创新，也不在没有结果时预设必须再做 v2。若只改善训练集、测试定位变差或误检明显增加，就不把它作为已成功模块。若取得一致收益，再考虑独立训练消融，区分三级结构和单尺度卷积的贡献。

## 10. 可用于汇报的准确表述

“我们在 SPPF 中构建池化与卷积两条互补路径。原路径保留多尺度最大响应，新路径用低通道深度卷积与空洞卷积形成尺度对应的可学习空间上下文，再融合到原模块输出。该设计旨在增强裂缝语义模式的表达，同时保留基线预训练结构。”

这是一项有明确机制和较低静态成本的工程候选。池化、深度卷积、空洞卷积、多分支融合均为已有技术；组合后的论文新颖性仍需进一步查重与消融，不能仅因重新命名就宣称首创。
